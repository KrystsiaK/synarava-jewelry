# Тест-кейсы для ручного тестирования админ-панели Synarava

Составлено по коду админки (`app/admin/**`, `components/admin/**`,
`lib/auth/**`, `lib/media/**`, `lib/admin/issues.ts`) по состоянию на
2026-09-12 — после Shopify-alignment и разбиения god-файлов
(`docs/history/admin-shopify-refactor-2026-09.md`, фазы 1–3).

- План работ по автоматизации: `docs/admin/test-plan-ru.md`
- Англоязычный каталог для авторов автотестов: `docs/admin/test-cases-playwright-en.md`
- Справочник поведения админки: `docs/admin/admin-guide-ru.md`

**Обозначения:**
- Приоритет: **P1** — блокер, **P2** — важно, **P3** — edge case.
- 🤖 — **кейс уже закрыт автотестом**, при ручном прогоне можно пропустить
  (оставлен для полноты картины).
- 🆕 — кейс добавлен в этой ревизии, ранее в каталоге отсутствовал.

## 16. Разрешённые вопросы

В прошлой ревизии каталог заканчивался тремя неоднозначностями. Все
разобраны по коду.

### 16.1 Дубликат слага/SKU (PROD-C13) — жёсткий отказ, не перезапись

Раньше был риск, что создание товара с занятым слагом молча перезапишет
существующий (`upsert`). **Этого больше нет.** Сохранение защищено дважды:
предварительной проверкой и перехватом ошибки уникальности на вставке.
Оба пути возвращают полевую ошибку, существующий товар не меняется.

### 16.2 Удаление hero-изображения коллекции (COL-09) — блокируется всегда

Проверка «hero-изображение обязательно» **не зависит от статуса**. Удалить
фото и сохранить нельзя ни в черновике, ни в опубликованной коллекции.
У товаров правило другое — там картинка обязательна только при публикации.
Асимметрия намеренная, и проверять стоит обе стороны.

### 16.3 Удаление картинки товара — два разных пути (PROD-C18 / PROD-C43)

Раньше каталог их смешивал:

- **Через форму** (флаг «убрать изображение»): картинка обнуляется, и если
  целевой статус Published или Unlisted — сохранение блокируется. Логично.
- **Через галерею** (кнопка «Remove» у изображения): удаляется запись,
  следующая картинка становится обложкой. Но если картинок больше не
  осталось — товар остаётся **без изображения, не меняя статус**.

То есть опубликованный товар можно оставить опубликованным и без картинки,
удалив последнее изображение из галереи. Проверка стоит только в сохранении
формы и на этом пути не срабатывает. Кейс PROD-C43 это фиксирует —
**до написания автотеста нужно решить с командой, баг это или задуманное
поведение**, иначе тест закрепит случайное поведение как ожидаемое.

### 16.4 Тайминг автосохранения (PROD-C36, COL-10)

Debounce — 700 мс. При ручной проверке подождите 1–2 секунды перед уходом
со страницы. В автотестах — опрос с таймаутом ~2 с, а не фиксированная пауза.
