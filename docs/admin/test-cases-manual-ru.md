# Тест-кейсы для ручного тестирования админ-панели Synarava

Составлено на основе анализа кода админки (`app/admin/**`,
`components/admin/**`, `lib/auth/**`, `lib/media/**`, `lib/admin/issues.ts`)
по состоянию на 2026-09-06. Часть базовых сценариев логина/лэйаута уже
покрыта автотестами в `e2e/admin-auth.spec.ts` — они тоже включены сюда для
полноты ручного прогона, но помечены `(есть автотест)`.

Обозначения приоритета: **P1** — блокер/критично, **P2** — важно, **P3** —
второстепенно/edge case.

---

## 1. Аутентификация и сессия

| ID | Название | Предусловия | Шаги | Ожидаемый результат | Приоритет |
|----|----------|-------------|------|----------------------|-----------|
| AUTH-01 | Гость редиректится на логин *(есть автотест)* | Нет активной сессии | Открыть `/admin` | Редирект на `/admin/login?redirectTo=%2Fadmin`, форма «Studio credentials» | P1 |
| AUTH-02 | Прямой заход на любую вложенную страницу без сессии | Нет сессии | Открыть `/admin/products`, `/admin/collections/new`, `/admin/videos` и т.д. напрямую | Каждый URL редиректит на `/admin/login?redirectTo=<этот URL>` | P1 |
| AUTH-03 | Успешный вход *(есть автотест)* | Известны корректные `ADMIN_USERNAME`/`ADMIN_PASSWORD` | Заполнить логин/пароль, нажать «Enter admin» | Редирект на `/admin`, виден «Admin studio» | P1 |
| AUTH-04 | Вход с неверным паролем | — | Ввести правильный логин, неверный пароль, отправить | Ошибка «Incorrect admin credentials.», сессия не создаётся, `/admin` недоступен | P1 |
| AUTH-05 | Вход с неверным логином | — | Ввести неверный логин, любой пароль | Ошибка «Incorrect admin credentials.» (текст не намекает, что именно неверно — логин или пароль) | P2 |
| AUTH-06 | Пустая форма логина | — | Отправить форму с пустыми полями | Клиентская валидация `required` не даёт отправить/сервер вернёт «Enter both an admin username and password.» | P2 |
| AUTH-07 | Пароль с пробелами в начале/конце | Известен корректный пароль | Ввести пароль с добавленным пробелом в конце | Вход отклонён как неверные креды (пароль не обрезается перед сравнением) | P3 |
| AUTH-08 | Rate limit после серии неудачных попыток | — | 10 раз подряд ввести неверный пароль с одного браузера/IP в течение 15 минут | На 11-й попытке — сообщение «Too many attempts. Try again in Ns.», кнопка входа блокируется и показывает обратный отсчёт | P1 |
| AUTH-09 | Сброс rate limit после успешного входа | Rate limit ещё не исчерпан | Один раз ввести неверный пароль, затем верный | Успешный вход возможен; счётчик неудачных попыток сброшен (следующие 10 неверных попыток снова доступны) | P3 |
| AUTH-10 | `redirectTo` ведёт на защищённую страницу после входа | — | Открыть `/admin/login?redirectTo=%2Fadmin%2Fproducts`, войти | После входа пользователь оказывается на `/admin/products`, а не на `/admin` | P2 |
| AUTH-11 | Open redirect защита — внешний домен | — | Открыть `/admin/login?redirectTo=https%3A%2F%2Fexample.com`, войти | После входа пользователь остаётся в админке (`/admin`), никакого перехода на внешний домен | P1 (security) |
| AUTH-12 | Open redirect защита — protocol-relative URL | — | `/admin/login?redirectTo=%2F%2Fexample.com`, войти | Редирект остаётся внутри `/admin`, внешний домен не открывается | P1 (security) |
| AUTH-13 | `redirectTo` не может зациклить на логин | — | `/admin/login?redirectTo=%2Fadmin%2Flogin`, войти | После входа — `/admin`, а не повторно `/admin/login` | P3 |
| AUTH-14 | Уже залогиненный пользователь открывает `/admin/login` | Есть активная сессия | Открыть `/admin/login` вручную | Мгновенный редирект обратно в админку, форма логина не показывается | P2 |
| AUTH-15 | Логаут *(есть автотест)* | Есть активная сессия | Нажать «Log out» | Редирект на `/admin/login`; повторный заход на `/admin` снова требует логина | P1 |
| AUTH-16 | Истёкшая сессия (>8 часов) | Сессия старше 8 часов (можно смоделировать правкой `expiresAt` в БД) | Открыть любую страницу админки | Редирект на логин, как у гостя | P2 |
| AUTH-17 | Cookie сессии не работает на витрине | Есть активная сессия | Проверить, что cookie не отправляется вне `/admin` (Path=/admin) | Cookie не должно быть видно на запросах к `/`, `/shop` и т.д. (DevTools → Network/Application) | P3 (security) |
| AUTH-18 | Незаданные `ADMIN_USERNAME`/`ADMIN_PASSWORD_HASH` | Переменные окружения не заданы (тестовый стенд) | Открыть `/admin/login`, попытаться войти | Ошибка «Admin auth is not configured…», вход невозможен ни с какими данными | P3 |
