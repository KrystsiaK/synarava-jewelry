| | |
|---|---|
| **Severity** | high |

Test: `adversarial-dead-code.inventory.test.ts` → `it.fails(... DEAD-001)`. |
| **Proposed minimal fix** | Import `parseShopifyWebhookJson` in products + reviews routes; drop raw `JSON.parse(rawBody)`. |
| **Estimated size** | XS |
| **Fix owner** | core/sync |
| **Safe-deletion confidence** | n/a (unify, not delete) — high confidence the dual path is real |
