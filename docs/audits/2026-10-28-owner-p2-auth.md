# Для владельца — фаза 2: доступ к админ-действиям

**Дата:** 28 октября 2026 (Europe/Lisbon)  
**Технический отчёт:** [2026-10-28-server-auth.md](2026-10-28-server-auth.md)

## Что мы нашли

Проверили серверные действия админки: есть ли проверка «вы вошли как админ» и нормальная проверка входных данных.

1. **AUTH-ADV-001 (высокий)** — действия политики SKU (загрузка / черновик / публикация) **не проверяют сессию админа**. Вызов без входа не должен проходить.
2. **AUTH-ADV-002 (средний)** — помощники «обновить сохранённый продукт/коллекцию/страницу» тоже без проверки сессии.

Важные мутации (сохранить/удалить продукт, push/pull, конфликты) — сессию уже требуют; это зафиксировано тестами.

## Что это значит для бизнеса

- Пока админка одна и URL не светится снаружи, риск ниже, но это **дыра в замке**: знание URL + возможность вызвать action = потенциальное чтение/запись SKU-политики без логина.
- Это не «магазин открыт всем», но чинить нужно до расширения доступа / новых интеграций.
