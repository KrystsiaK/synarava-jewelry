4. **DEAD-006 (низко)** — старые имена-алиасы экспортов ещё живут рядом с новыми.

Ложные срабатывания knip (моки Storybook, скрипты sku-api) — **не трогать**.

## Что это значит для бизнеса

- Пункт 1 — не «уборка», а риск неверных id при вебхуках (см. фазу 5).
- Остальное — стоимость поддержки и шум в CI, не дыры витрины.
